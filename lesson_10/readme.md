# Документация проекта автоматизации тестирования интернет-магазина SauceDemo
# Описание базового синтаксиса записи и форматирования

Проект использует следующие технологии и синтаксис:
*Python*: Основной язык программирования для написания тестов.
*Selenium*: Библиотека для автоматизации взаимодействия с веб-браузером (WebDriver).
*Pytest*: Фреймворк для написания, параметризации и запуска тестов.
*Allure*: Инструмент для генерации наглядных HTML-отчетов о выполнении тестов.
*Page Object Model (POM)*: Паттерн проектирования, разделяющий логику страниц (shop_page.py) и тестовые сценарии (test_shop.py).

# Форматирование кода
- Код форматируется в соответствии со стандартом PEP 8. Рекомендуется использовать автоформаттеры black или ruff.
- Используются docstrings для документирования всех классов Page Object и методов фикстур.
- Все шаги теста размечаются с помощью декораторов @allure.step внутри классов POM или контекстных менеджеров with allure.step() непосредственно в тестах для улучшения читаемости отчетов.
- Тесты размечаются мета-данными: @allure.title, @allure.feature, @allure.severity.

# Подготовка окружения
- Перед запуском убедитесь, что у вас установлены актуальные версии браузеров (Chrome / Firefox) и соответствующих WebDriver'ов (chromedriver, geckodriver), доступных в системной переменной PATH. Для автоматического управления драйверами можно использовать библиотеку webdriver-manager.


# Запуск полного сценария покупки товаров (SauceDemo):
```bash
pytest lesson_10/test_shop.py --alluredir=./reports
```

Эта команда запустит тесты и сохранит сырые данные для отчета в директорию ./reports.

# Инструкция по просмотру сформированного отчета Allure

- Убедитесь, что установлен инструмент командной строки Allure. Если нет — установите его согласно официальной инструкции.
- После завершения выполнения тестов откройте отчет командой:
```bash
allure serve ./allure-results
```
Эта команда запустит локальный веб-сервер и автоматически откроет детальный отчет в браузере по умолчанию.

# В отчете Allure вы увидите:
- Название теста и параметры: Например, Покупка товаров на SauceDemo: авторизация 'standard_user'.
- Описание теста (Description): Что именно проверяет данный сценарий.
- Метки (Labels): Feature (Интернет-магазин), Story (Оформление заказа), Severity (Critical).
- Графики и статистика: Доля успешных/упавших тестов, история запусков.
- Дерево шагов теста: Подробная иерархия действий (Открытие страницы -> Авторизация -> Добавление товаров -> Оформление...).
- Скриншоты при падении: Если тест упал, к шагу, на котором произошла ошибка, будет прикреплен скриншот экрана (при наличии соответствующего хука в conftest.py).
- Результат: Статус «Passed» (успешное выполнение) или «Failed» с трассировкой стека и указанием ожидаемого и фактического результата.
